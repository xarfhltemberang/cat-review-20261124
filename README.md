# Cat Reviews Its Human

A make.fun entry for [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

`main.py` (Python 3.13, standard library only) writes one funny single-line
one-star review, written by a house cat about its human, to
`/output/entry.txt` — under 200 characters, deadpan review shape, with a
complaint only a cat would make.

## The entry

> One star. He moved my bowl two inches to the left, so legally it is empty. I have been screaming about this since Tuesday and will continue until Thursday.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
